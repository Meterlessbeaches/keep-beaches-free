# GoatCounter Setup Guide

## 🐐 What is GoatCounter?
- **Free** privacy-focused web analytics
- **No cookies** or personal data collection
- **Open source** and self-hostable option
- **Perfect for GitHub Pages**

## 🚀 Quick Setup (2 minutes)

### 1. Sign Up
1. Go to: https://goatcounter.com/
2. Click "Sign up" (free tier is fine)
3. Choose "Hosted" (easier option)

### 2. Create Site
1. After signup, click "New site"
2. Enter your site details:
   - **Site name:** `keep-beaches-free`
   - **Site domain:** `yourusername.github.io`
   - **Code:** `keep-beaches-free` (or any code you want)

### 3. Get Your Counter URL
1. Your counter URL will be: `https://keep-beaches-free.goatcounter.com/count`
2. Copy this URL

### 4. Update index.html
Replace in index.html line 116:
```html
<script data-goatcounter="https://keep-beaches-free.goatcounter.com/count"
        async src="//gc.zgo.at/count.js"></script>
```

### 5. Deploy to GitHub Pages
1. Commit and push changes
2. GoatCounter will start counting visits

### What You'll See
- **Total page views**
- **Daily visitors** (approximate)
- **Referrer sources** (where people came from)
- **Browser/OS stats**
- **Popular pages**

## Privacy Features

### What GoatCounter DOESN'T Track
- No cookies
- No personal data
- No IP addresses stored
- No tracking across sites
- No fingerprinting

### What It DOES Track
- Page views (count only)
- Approximate location (country level)
- Referrer (which site linked here)
- Browser type (general)
- Time of visit
